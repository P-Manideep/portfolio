# Manideep Pothkan — Portfolio

Dark, responsive developer portfolio. No framework or paid service required.

## Run locally
Open `index.html` directly in a browser.

## Included
- Responsive developer portfolio
- Project filtering
- Scroll reveal animations
- Interactive resume preview + download
- GitHub / LinkedIn / email actions
- Mobile navigation
- Resume PDF in `public/Manideep-Pothkan-Resume.pdf`

## Free deployment
Use GitHub Pages. Create a public repository, upload `index.html` and the `public` folder, then enable Pages from Settings → Pages. GitHub Pages is available on GitHub Free for public repositories.
